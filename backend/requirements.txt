# CareerLens AI — backend runtime dependencies
# Python 3.12 (pinned in .python-version).
#
# Why 3.12 and not the system 3.14 (plan environment note E1):
#   spaCy 3.8.x publishes cp314 wheels, but thinc >= 9.0.0 publishes cp39-cp312
#   only. spaCy declares thinc >=8.3.4,<9.3.0, so a fresh resolver on 3.14
#   prefers thinc 9.1.1 and attempts a multi-minute Rust/Cython source build
#   that commonly fails. Pinning the interpreter to 3.12 removes the whole class
#   of problem: every wheel in this stack ships a cp312 binary.
